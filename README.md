## Installation

1. Clone the repository:
```bash
git clone https://github.com/manumanu22022001-netizen/accounting-AI.git
cd accounting-AI
```

2. Install dependencies:
```bash
pip install -r requirements.txt
```

3. Run the chatbot locally:
```bash
streamlit run app.py
```

The app will open in your browser at `http://localhost:8501`

## Deployment on Streamlit Cloud

### Quick Deploy (Recommended)

1. Go to [Streamlit Cloud](https://share.streamlit.io)
2. Click **"New app"**
3. Select:
   - **GitHub repo**: `manumanu22022001-netizen/accounting-AI`
   - **Branch**: `main`
   - **Main file path**: `app.py`
4. Click **"Deploy"**

Your app will be live in a few minutes! You'll get a shareable URL.

### Manual Steps (if needed)

If the above doesn't work:
1. Ensure your GitHub repository is public
2. Connect your GitHub account to Streamlit Cloud
3. Follow the steps above
